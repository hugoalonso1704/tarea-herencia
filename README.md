# tarea-herencia

Ejercicio de herencia de clases en Python.

## Clases

- **Persona**: nombre y edad.
- **Cliente** (hereda de `Persona`): añade dinero, sexo y, opcionalmente, color de pelo, color de ojos y número de teléfono.
- **Producto**: nombre, precio y stock.

## Función

`comprar_producto_cliente(cliente, producto, unidades)`: comprueba que haya stock y que el cliente tenga dinero suficiente; si es así, descuenta las unidades del stock y el importe del dinero del cliente.

## Cómo ejecutarlo

```
python tarea-herencia.py
```
